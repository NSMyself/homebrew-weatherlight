# homebrew-weatherlight

Homebrew tap for [Weatherlight](https://weatherlight.app) — a private,
local-first, searchable memory for your bookmarks.

## Install

```bash
brew tap NSMyself/weatherlight
brew install weatherlight
```

See [ALPHA.md](ALPHA.md) for setup and usage.

## Requirements

- macOS Sonoma (14.0) or newer
- Apple Silicon only

## What this repo is

This repo hosts the Homebrew formula and release binaries. Weatherlight's
source lives in a separate private repository.
